# Dusun English Malay Parallel Corpus

A trilingual dataset containing Dusun, English, and Malay words, phrases, and sentences compiled for linguistic research, dictionary development, and machine translation.
This dataset is based on the Dusun language as spoken by the Dusun ethnic group of Sabah, Malaysia. While the dialect shares approximately 99% similarity with standardized Kadazandusun, there may be minor differences in vocabulary, spelling, and standardisation. Researchers working on Kadazandusun NLP may find this dataset largely applicable.

## Overview

This corpus contains approximately **26,000 entries** (Feb, 2026), including:

- ~9,000 single-word translations  
- ~16,000 phrases and full sentences  
- Multiple translation variants  
- Word types and grammatical categories  

The dataset is intended for:

- Natural Language Processing (NLP)
- Machine Translation (MT / NMT)
- Dictionary development
- Language preservation
- Educational use
- Low-resource language research

Dusun is an indigenous language spoken in Sabah, Malaysia.

## Dataset Contents

Each row represents a translation unit with structured linguistic information.

Typical fields include:

- Dusun text
- English translation
- Malay translation
- Type (word / phrase / sentence)
- Category (semantic or grammatical)
- Variants or alternative forms

## Notes on the Language

- Based primarily on the Dusun dialect used in Sabah, Malaysia
- Closely related to Kadazan and other Dusunic languages  
- Considered a low-resource language in computational linguistics

## Limitations

- Not an exhaustive representation of the language  
- May contain dialectal variations  
- Some translations may be context-dependent  
- Sentence coverage is not domain-specific
